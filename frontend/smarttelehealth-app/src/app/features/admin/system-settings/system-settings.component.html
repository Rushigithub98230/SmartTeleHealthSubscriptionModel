About System Settings

System settings provide global defaults that are automatically applied to new subscription plans. This ensures consistency across all plans while allowing individual plan customization.

How it works:
  • Admin Commission: Automatically applied to plan creation forms
  • Price Change Notice: Used for plan modification notifications
  • Payment Attempts: Controls automated billing retry behavior
